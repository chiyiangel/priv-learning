## 1　怎么读这一章

约有 60 个方法分在两章：本章是通用 SfM 的六个阶段，下一章是 360 / 全向 / 鱼眼专项。每个方法一张卡片：

- **标签**：“通用”表示不针对 360，“360 / 鱼眼”表示专为或明确适用于 360 / 鱼眼，“部分适用”表示有一部分可迁移。
- **验证 / 报告增益**：只写来源原文中出现的内容。没有数字的地方没有补。
- **推断 / 备注**：紫色“推断”是调研者自己的判断，不是来源所述。

::: warn 证据边界
- 多数通用方法的“报告增益”只来自摘要，没有补读正文表格。
- VGGT、π³、MapAnything 等的具体位姿指标（如 AUC）没有逐篇读正文，所以未写入。
- 许可证以仓库当前 LICENSE 为准，标“未核实”的项目没有逐条确认。
:::

## 2　按阶段浏览

下表给出每个阶段的“一句话结论”，卡片在后面。

| 阶段 | 要点 |
|---|---|
| 特征与匹配 | 若当前用 SIFT 一类传统特征，换成 ALIKED / DISK + LightGlue 是投入最小的升级（推断）；稠密匹配（RoMa、MASt3R）为针孔图像训练，鱼眼更稳妥的做法是先切成针孔切片（推断） |
| 精修 · BA · 相机模型 · 卷帘 | 模型是否贴合镜头直接决定边缘残差；特征度量精修（Pixel-Perfect）提升亚像素精度；COLMAP 3.10–4.2.1 的 changelog 里检索不到卷帘模型，两篇卷帘 BA 论文的代码许可均未核实 |
| SfM 系统 | COLMAP 4.x 已吸收 GLOMAP 全局 SfM、球面 / EUCM 相机、GPU BA 与重力先验 |
| 先验 | 重力对齐旋转平均与 rig 约束，是 IMU 先验里最“即插即用”的 |
| 前馈 / 学习式 | 训练域是针孔图像；更适合作初始化或粗检，不是最终位姿 |
| 辐射场 / 3DGS 联合位姿 | 位姿与场景一起优化，收益可观，但“更准的渲染”不等于“更准的位姿” |
